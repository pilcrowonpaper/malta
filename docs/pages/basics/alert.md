# Adding an alert

Add a banner alert with a message and link to all pages with the `alert` config.

```json
{
	"alert": {
		"message": "This website has been replaced and is no longer maintained.",
		"link_text": "Go to example.com",
		"link_url": "https://example.com"
	}
}
```
